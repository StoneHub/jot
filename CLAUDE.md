# Jot

Read [AGENTS.md](AGENTS.md) for project agreements.

For a cloud task, start with [docs/CLOUD-WORK.md](docs/CLOUD-WORK.md) and the assigned task packet. The current Swift package requires Apple SDKs; installing Swift on Linux does not make it buildable. Cloud work returns a scoped PR and evidence to the local integrator for any outstanding Mac validation.

For local app work, use the repository's build/install workflow and preserve capture and history. A cloud task does not authorize app installation or shell configuration changes.
