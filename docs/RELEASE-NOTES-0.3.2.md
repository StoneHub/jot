# Jot 0.3.2

Activity now features live Mac-impact statistics, CPU and memory line charts, and dictation and ambient-use insights in a responsive layout. Removed the capture-event list. Paused housekeeping and diagnostic logging run about once a minute; Activity charts refresh once a minute and usage totals every five minutes while the tab is active. Fn dictation remains immediate. Agents can read aggregate usage through the activity_report MCP tool and jot activity CLI. This development-signed prerelease updates through Jot on Macs that trust the existing development certificate.
