# Jot

A native Mac utility for local dictation and ambient transcripts. Hold Fn to dictate; keep searchable transcripts locally. Audio is temporary, and ambient speech is context, never an instruction to execute.

The app implementation is being reviewed in [PR #2](https://github.com/StoneHub/jot/pull/2). See the [implementation branch](https://github.com/StoneHub/jot/tree/feat/native-speech-service) for source, build instructions, and verification.
